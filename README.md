# Rubicon Extra Additions

## A Rubicon Engine addon to help bridge the gap from default FNF to Rubicon. It's not a huge addon but it can be helpful in some cases for more traditional mods.

### Current intended features:
 - Basic setting system
   - This is not meant to be overwritten, these have a set amount of basic settings such as V-Sync, any mod specific settings should be done manually.
 - Pause menu class
 - Countdown class
 - Note positioning (Down scroll and up scroll toggle)
 - Loading screen class
 - Simple debug UI more akin to something you'd see in something like Codename Engine
 - Key press camera offsets
 - Volume slider

### Potential features:
 - Mod specific setting system

### There are some features that Rubicon may add natively, the current ones that are on the "chopping block" so to speak are listed here, so using them in your projects may be unnecessary in the future when or if they are added to the basic Rubicon package:
 - Setting system
 - Countdown class
